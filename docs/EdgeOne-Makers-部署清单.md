# EdgeOne Makers 部署操作清单（assl.site）

> 本文档为官网门户部署到腾讯云 EdgeOne Makers 的完整操作清单，基于官方文档整理，
> 并结合本项目（Astro 静态站）实际配置。界面如有更新，以控制台实际为准。

## 前置条件

- [x] 代码已推送到 GitHub：`https://github.com/shiaa/jia-gw`（分支 `main`）
- [x] `package.json` 中已有构建脚本 `npm run build`，产物目录为 `dist/`
- [ ] 腾讯云账号（可微信/QQ/手机号快速注册）
- [ ] 域名 `assl.site` 已完成域名注册并可在域名服务商处配置 DNS

## 一、创建 Makers 项目（Git 集成）

### 1. 登录并开通
1. 访问 EdgeOne Makers 控制台（或通过腾讯云控制台搜索"EdgeOne Makers"进入）。
2. 首次使用点击 **"立即开通"** 开通服务。

### 2. 绑定 GitHub 并选择仓库
1. 在项目创建页，单击 **"Github"** 连接仓库。
2. 授权 EdgeOne 访问你的 GitHub 仓库（建议授权本仓库）。
3. 选择仓库 `shiaa/jia-gw`。

### 3. 配置构建设置

| 配置项 | 填写的值 | 说明 |
|--------|----------|------|
| 部署分支 | `main` | 推送到该分支自动触发部署 |
| 构建命令 | `npm run build` | 对应 `package.json` 的 build 脚本 |
| 安装依赖命令 | `npm install`（默认） | 无特殊依赖，默认即可 |
| 构建产物目录 | `dist/` | Astro 静态站默认输出目录 |
| Node 版本 | `>=22.12.0` | 项目 `engines` 要求，选择 22 或以上 |

> ⚠️ **重要**：本项目使用 TailwindCSS v4（`@tailwindcss/vite`），依赖 `@tailwindcss/vite` 包，
> 无需额外配置，`npm install` + `npm run build` 即可完成构建。

### 4. 选择加速区域（备案策略）

| 阶段 | 加速区域 | 是否需备案 |
|------|----------|-----------|
| **上线初期** | 海外 / 香港 | 免备案，可立即绑定域名 |
| **备案通过后** | 大陆 | 需备案号 `粤ICP备2026111683号` |

> 推荐：先选 **海外/香港** 区域立即上线，备案通过后再切换大陆区域。

### 5. 开始部署
1. 确认配置无误后，单击 **"开始部署"**。
2. 等待自动构建部署到全球边缘网络，页面显示"成功"状态。
3. 部署完成后，会生成一个 Makers 默认访问域名（形如 `xxxx.pages.edgeone.app`），可用于临时访问验证。

## 二、绑定自定义域名 assl.site

### 1. 添加自定义域名
1. 在项目 **域名管理** 中添加自定义域名 `assl.site`。
2. 建议同时添加 `www.assl.site`，并设置 `www` 301 跳转到裸域（或在 DNS 层直接 CNAME 到同一目标）。

### 2. 配置 HTTPS 证书
- 在域名管理中申请**免费证书**（EdgeOne 托管证书），或使用已有 SSL 证书。
- 证书绑定后，站点默认启用 HTTPS。

### 3. 配置 DNS 解析
在域名服务商处（注册商或当前 DNS 托管方）添加记录：

| 记录类型 | 主机记录 | 记录值 |
|----------|----------|--------|
| CNAME | `@` | Makers 分配的目标地址 |
| CNAME | `www` | Makers 分配的目标地址 |

> 等待 DNS 生效（通常几分钟到几小时），即可通过 `https://assl.site` 访问。

## 三、更新流程

代码本地修改 → 推送 `main` 分支 → Makers 自动构建部署：

```bash
git add -A
git commit -m "更新说明"
git push origin main
```

推送后无需手动操作，EdgeOne 自动拉取最新提交并部署。

## 四、验证清单

部署完成后逐项检查：

- [ ] `https://assl.site` 正常访问，首页各区块渲染正常
- [ ] `/about` `/contact` `/products/ssl` 子页面可访问
- [ ] `/legal/privacy` `/legal/terms` 合规页可访问
- [ ] 页脚显示备案号 `粤ICP备2026111683号`
- [ ] HTTPS 证书生效（浏览器地址栏安全锁）
- [ ] 右下角在线客服悬浮按钮可打开

## 五、常见问题

| 问题 | 解决方案 |
|------|----------|
| 构建失败 | 检查 Node 版本是否 ≥22；确认 `npm install` 成功 |
| 页面 404 | 确认产物目录为 `dist/`；Astro 默认路由与文件名对应 |
| 大陆无法访问 | 当前为海外加速区域，备案通过后切换大陆区域 |
| 域名未生效 | 检查 CNAME 记录是否正确、DNS 是否已生效 |
